# 学生任务分级与客观验收

## 组织方式

建议 2—3 名本科生、6 周，每人每周 6—8 小时。三类职责可以轮换：数学与形式化、Agent 工程、独立测试与评测。教师每周用 30 分钟审查一次目标陈述和证据；不要求学生先掌握完整的设备无关自检验理论。

先修仅包括函数、逻辑、布尔运算、向量与矩阵乘法、Python 基础。Lean 的类型、定理、tactic、函数外延性可在项目中学习。量子部分先按“带 ±1 系数的有限向量及其变换”理解，再补充物理解释。

## 分级任务

| 级别 | 任务 | 必须交付 | 通过标准 |
|---|---|---|---|
| L0（入门） | 复现环境，解释 XOR 与普通差分 | 环境版本、CI/本地日志、24 行 CCZ 表 | 一键验收成功；能给出两种导数不同的输入 |
| L1（证明） | 独立重写 CCZ 三个导数及一个错误结论的否定 | Lean 源码、自然语言解释、审计输出 | 三个全称结论编译；无 sorry/新公理；反例具体可复核 |
| L2（工具） | 接入一个真实模型，实现反馈修复 | 未编辑的逐轮 JSON、模型名、token、耗时 | 至少保留一次真实失败和后续修复；目标 hash 全程不变；失败不得删去 |
| L3（数学） | 解释并独立重建一般稳定子证明 | 定义对应表、Z/X 证明、非零证明 | 任意 n,f；覆盖非对角项；说明相位在原像处取值 |
| L4（验证） | 增加新 Boolean-phase 家族和非对称测试，尝试复数归一化桥接 | 交叉验证、语义攻击测试、形式化边界表 | 可定位索引/相位/归一化错误；未证明项保持显式标注 |
| L5（研究） | 迁移到至少两个非量子问题族，做对照实验 | 数据集、固定划分、基线、统计与误差分析 | 真实模型实验；避免模板/答案泄漏；能复现正负结果 |

## 六周进度

| 周 | 工作 | 当周检查 |
|---|---|---|
| 1 | 学习 Bool、Lean、运行原 Python 测试，完成 L0 | 每人解释一个反例；独立运行验证 |
| 2 | 手写 CCZ 证明，构造错误命题；审查陈述 | 每人不看答案重建至少一个证明；核查量词 |
| 3 | 接入模型，保留失败轨迹；比较无反馈/有反馈 | 10—20 个开发任务，小预算试跑；不声称论文效果 |
| 4 | 学习一般稳定子，做 cross-language 和变异测试 | 正确变异应保留、错误变异应检出；记录漏检 |
| 5 | 迁移至布尔代数、有限置换/群作用或小型组合恒等式 | 冻结隐藏问题族；审查参考陈述及否定样本 |
| 6 | 完成等预算对照、误差分类和演示报告 | 决定继续研究、改问题或止于优秀课程项目 |

## 基础验收门槛

1. `python scripts/verify.py` 返回 0，验证报告为 PASS，环境错误不得被跳过。
2. CCZ 全部 24 个输入/变量组合通过；3 个 Lean 导数定理与 2 个否定定理编译通过。
3. 两个通用稳定子定理、非零定理通过，并解释符号向量与原矩阵定义的关系。
4. 公理集合仅含批准的标准依赖；任一 `sorryAx`、额外公理、native 证明捷径均失败。
5. 精确实例检查 804 组；矩阵检查 32 个函数；Lean/Python 49,680 行逐项一致、无缺行和重复。
6. Agent 不能修改 statement/binders/import；编造引理和错误证明被真实 Lean 拒绝；逐次请求、反馈和目标 hash 留档。
7. 5 个正确任务的 replay 经失败后修复成功，2 个错误任务不通过；清楚说明这些数字不是 LLM 能力指标。
8. 学生新增真实模型实验必须标注模型、预算、调用次数、失败数、超时数、输入上下文、token 和费用。未接通模型不能领取 L2 的“真实调用”成绩。

## 评分建议（100 分）

| 内容 | 分值 | 扣分重点 |
|---|---:|---|
| 数学语义与定义 | 25 | 偷换 XOR、漏量词、加入结论作为假设、把零向量当态 |
| Lean 证明与审计 | 25 | sorry、新公理、导入目标答案、无法解释证明 |
| Agent 流程与日志 | 20 | 手工修复冒充自动、删除失败、将回放称为模型结果 |
| 独立测试与反例 | 20 | 只测对称例子、实现互相抄写、只比较最终 PASS |
| 研究判断与复现 | 10 | 将小样本包装为泛化、混淆未归一化理想模型与自检验 |

出现证明绕过、隐去实验失败或虚构实测结果时，该项必须重做。是否产生新量子定理不作为前四周的验收要求；可迁移的能力是目标分解、接口设计、严谨判断和可复现实验。
