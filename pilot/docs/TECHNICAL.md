# 技术说明与信任边界

## 数学表示与代码对应

上游基线是 `6c28d91163bc728999fef7b04ba54ae773fe58e9`，本试点保留 `src/boolean_phase_core.py` 与原测试不变，所有新增代码放在 `pilot/`（外加独立 CI）。

上游布尔导数：

\[
\partial_i f(x)=f(x_{i\leftarrow0})\oplus f(x_{i\leftarrow1}).
\]

它等于 `f(x) XOR f(flip_i(x))`，且 `∂ᵢf(flipᵢx)=∂ᵢf(x)`。三个 CCZ 结论由 Bool 的完整分类讨论给出证明项，经内核检查。不是把 Python 的通过结果作为 Lean 公理导入。

定义整数符号 `s(p)=if p then -1 else 1` 和精确振幅

\[
\psi_f(a,b)=\delta_{a,b}s(f(a)).
\]

算子用基底系数的作用表示：

\[
(S_i^Zv)(a,b)=s(a_i)s(b_i)v(a,b),
\]

\[
(S_i^Xv)(a,b)=s(\partial_i f(\mathrm{flip}_i b))
 v(\mathrm{flip}_i a,\mathrm{flip}_i b).
\]

第二式在“原像”处求相位，对应上游矩阵乘积 `X_A X_B D_B` 的右端先作用约定。证明分 `a=b` 与 `a≠b`：非对角处靠 flip 的单射性；对角处靠 `s(p XOR q)s(p)=s(q)` 消去符号。`choi_nonzero` 通过全零比特串处振幅为 ±1 排除零向量。

因此 Lean 证明了非零整数振幅向量被两类算子固定。把整数嵌入复数并乘 `2^(-n/2)` 后，数学上得到通常的归一化态关系；**该嵌入、标量线性性、归一化和 tensor/matrix 对应尚未在 Lean 中实现**。它们是明确的后续任务，不能用 49,680 行比对代替。

注意：把同一位的 `D` 与 `X_A X_B` 交换并不会破坏此稳定子。导数对该位翻转不变，所以它们可交换。将其误当成错误案例，本身就是值得测试的“形式正确但数学判断错误”。

## 从自然语言到验收的完整流程

1. **命题整理**：记录域、变量范围、自然语言目标、允许的假设、符号约定、原始来源。区分求证明、求反例和超出范围的命题。
2. **形式化提案**：`formalize.py` 输出任务卡；外部模型据定义生成 import/binders/statement，不生成证明。现有种子任务可与固定参考作严格字符串对照。
3. **语义审核**：新任务由人检查域、量词、假设、结论及非空性；不同形式的等价性可另写双向蕴含证明。编译本身不完成这一步。参考匹配不是通用语义判断器。
4. **冻结契约**：证明程序从可信任务注册表重建 theorem；提案只能包含 `statement_sha256` 与 `proof`。新增假设、改成 `True`、改变定义等均拒绝。
5. **生成证明**：外部 provider 获取固定目标、允许的定义/辅助引理和最近一次完整错误反馈，返回证明体。CCZ 任务只导入 Definitions，稳定子任务只导入 Basic，均不导入自身目标定理。
6. **检查**：词汇门禁 → Lean 编译（20 秒/200000 heartbeats）→ `#print axioms`。标准逻辑公理白名单为 `propext`, `Classical.choice`, `Quot.sound`。本次实际证明只使用前者及 `Quot.sound`；两个反例否定无公理依赖。
7. **反馈和修复**：编译错误交回模型，最多预设次数；不自动修改定义、目标和测试。超时、基础环境错误和无法完成分别记账。
8. **独立复核**：独立前向稀疏实现 → 上游 numpy 矩阵实现 → Lean 导出结果逐项比较。
9. **记录结果**：源码 hash、提交 SHA、toolchain、目标 hash、逐轮输入/输出、编译日志、耗时、公理集合、未完成状态。真实模型另存版本、采样参数、token、价格日期。

`VERIFIED` 的含义仅是注册表里的形式化陈述获准证明。`UNRESOLVED` 不能改名为 false；“为假”须提供经核实的反例或否定证明。本次两个故意错误的导数命题既有 Python 反例，也有 Lean 否定证明。

## 三条独立证据链

| 层次 | 方法 | 覆盖 | 能说明什么 |
|---|---|---|---|
| Lean | 内核检查的符号证明 | 任意有限 n；任意 f | 所选定义下的精确整数振幅定理 |
| Python 精确实现 | 整数、真值表、前向作用 | n=1,2,3 的全部 276 个布尔函数，804 个“函数×位”组合 | 这些有限实例满足恒等式 |
| 原 numpy 实现 | 复数矩阵与归一化态 | n≤2 全部；n=3 固定 12 个非随机函数，总 32 个函数 | 与既有参考实现的约定一致到 1e-12 |
| Lean→Python | CSV 每行复核并检查无重复/无缺行 | 49,680 行 | 两种实现的取位、索引、振幅、算子计算在有限样本上一致 |

32 个矩阵函数中的 CCZ 真值表编号为 128；n=3 使用 `[0,1,7,23,42,85,127,128,170,213,254,255]`。高位优先、A 在前 B 在后的约定与上游一致。含非对称函数的测试才能有效发现位序反转；只测 CCZ 会漏掉某些错误。

## 验收与安全范围

无 `sorry` 只是第一层。还需要公理审计、正确 imports、陈述固定和语义核对。`native_decide` 被排除，以免扩大本试点所选的证明信任基础；普通 `decide` 允许。

本项目没有以 Lean 处理不可信任意代码为目标。provider 程序本身由操作者选择；若给它整个仓库访问权，它可能读取公开答案，不能用于论文中的无泄漏评测。真正实验应只挂载定义及允许的辅助引理，以独立目标文件和只读环境运行，并记录输入快照。不要把 `replay`、参考答案、CI 已公开的任务计入隐藏测试集。

当前词汇限制偏向小型布尔与稳定子证明，会拒绝某些正确证明写法。这是保守工程限制，应单独报告 `POLICY_REJECTED`，不应全部算为模型数学失败。自动形式化严格字符串匹配也有同样的等价写法误拒绝问题。
